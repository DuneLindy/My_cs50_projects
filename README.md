# CS50's Introduction to Artificial Intelligence with Python

This repository contains my projects and implementations from **Harvard University's CS50AI** course, exploring foundational concepts and algorithms in modern artificial intelligence.

## Repository Structure

* **0. Search** – Graph search algorithms (BFS, DFS, A*, Minimax) applied to pathfinding and adversarial games.
* **1. Knowledge** – Propositional logic, model checking, and logical inference systems.
* **2. Uncertainty** – Probability theory, Bayesian networks, and Markov models.
* **3. Optimization** – Local search, linear programming, and constraint satisfaction problems.
* **4. Learning** – Supervised and reinforcement learning models.
* **5. Neural Networks** – Deep learning and computer vision using neural network architectures.
* **6. Language** – Natural language processing (NLP), syntax parsing, and language models.

## Technologies Used
* **Language:** Python 3
* **Libraries:** NumPy, pandas, scikit-learn, TensorFlow / PyTorch, NLTK
